✅ สรุป Spec

• Route: /help — protected, เพิ่มใน App.tsx เหมือน /dashboard
• หน้าแรก: 6 category cards ในตาราง 3 คอลัมน์
• คลิก category → แสดง module cards ของหมวดนั้น (ใน state เดียวกัน)
• คลิก module card → modal รายละเอียด (ไม่ navigate ออก)
• Language toggle TH/EN อยู่ที่หน้าหลักที่เดียว — modal ตาม state
• เนื้อหาทั้งไทยและอังกฤษ embed ใน component โดยตรง (ไม่ต้องเรียก API)
• ไม่ต้องสร้าง backend module — เป็น static page
