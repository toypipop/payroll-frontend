# คู่มือการใช้งานระบบ Payroll Pro

เอกสารฉบับย่อสำหรับผู้ใช้งานทุกบทบาท เช่น Admin, HR, Payroll, Manager และ Staff โดยเน้นขั้นตอนการทำงานหลักของระบบ ไม่ลงรายละเอียดเชิงเทคนิค

ข้อมูลในคู่มือนี้ใช้ข้อมูลตัวอย่าง เช่น บริษัท Alpha Co., Ltd., Beta Co., Ltd. และพนักงานตัวอย่าง

## ภาพรวมระบบ

Payroll Pro เป็นระบบสำหรับจัดการข้อมูลพนักงาน การลงเวลา การลา การตั้งค่าเงินเดือน การประมวลผลเงินเดือน และการออกรายงานที่เกี่ยวข้อง เช่น สลิปเงินเดือน รายงานโอนเงินธนาคาร รายงานประกันสังคม และรายงานภาษี

ผู้ใช้งานแต่ละคนอาจเห็นเมนูไม่เท่ากัน ขึ้นอยู่กับบทบาทและสิทธิ์ที่ Admin กำหนดไว้

[ใส่ภาพหน้าจอ: หน้า Dashboard หลังเข้าสู่ระบบ]

## การเข้าสู่ระบบ

1. เปิดเว็บ Payroll Pro
2. กรอก Email และ Password
3. กด `Sign In`
4. เมื่อเข้าสู่ระบบสำเร็จ ระบบจะเปิดหน้า Dashboard

ตัวอย่างบัญชี:

| บทบาท | Email ตัวอย่าง | หมายเหตุ |
|---|---|---|
| Admin | admin@admin.com | ใช้สำหรับดูแลระบบทั้งหมด |
| HR | hr@example.com | ใช้จัดการพนักงาน เวลา และการลา |
| Payroll | payroll@example.com | ใช้ประมวลผลเงินเดือนและรายงาน |
| Staff | staff@example.com | ใช้ดูข้อมูลที่ได้รับสิทธิ์ |

ข้อควรระวัง:

- ห้ามแชร์รหัสผ่านให้ผู้อื่น
- หากเข้าสู่ระบบไม่ได้ ให้ตรวจสอบ Email, Password และการเชื่อมต่อระบบ
- เมื่อใช้งานเครื่องร่วมกัน ควรออกจากระบบทุกครั้ง

[ใส่ภาพหน้าจอ: หน้า Login]

## Dashboard

ใช้ดูภาพรวมของระบบ เช่น จำนวนพนักงาน รอบเงินเดือน และทางลัดไปยังงานสำคัญ

ขั้นตอนใช้งาน:

1. เข้าสู่ระบบ
2. เปิดเมนู `Dashboard`
3. ตรวจสอบข้อมูลสรุป
4. กดทางลัด เช่น Employees หรือ Payroll Cycles เมื่อต้องการไปทำงานต่อ

ข้อควรระวัง:

- ตัวเลขใน Dashboard ขึ้นอยู่กับสิทธิ์และบริษัทที่ผู้ใช้เข้าถึงได้
- หากข้อมูลไม่ครบ ให้ตรวจสอบสิทธิ์ของผู้ใช้หรือข้อมูลตั้งต้นของบริษัท

[ใส่ภาพหน้าจอ: Dashboard พร้อมกล่องสรุป]

## Employees

### Employee List

ใช้จัดการข้อมูลพนักงาน เช่น ข้อมูลส่วนตัว บริษัท แผนก ตำแหน่ง บทบาท ประเภทการจ้างงาน และบัญชีธนาคาร

ขั้นตอนเพิ่มพนักงาน:

1. เปิดเมนู `Employees > Employee List`
2. กด `+ Add Employee`
3. เลือกบริษัท เช่น Alpha Co., Ltd.
4. กรอกข้อมูลพนักงาน เช่น ชื่อ นามสกุล Email วันที่เริ่มงาน
5. เลือก Department, Position, Role และ Employment Type
6. กรอกข้อมูลธนาคารถ้ามี
7. กด `Save`

ขั้นตอนแก้ไขพนักงาน:

1. ค้นหาพนักงานจากตาราง
2. กด `Edit`
3. แก้ไขข้อมูลที่ต้องการ
4. กด `Update`

ข้อควรระวัง:

- บริษัทของพนักงานเป็นข้อมูลหลักที่ใช้กับเงินเดือน เวลาเข้างาน และการลา
- Department, Position, Role และ Employment Type จะสัมพันธ์กับบริษัทที่เลือก
- การลบพนักงานอาจกระทบข้อมูลเงินเดือนหรือรายงานย้อนหลัง

[ใส่ภาพหน้าจอ: หน้า Employee List]
[ใส่ภาพหน้าจอ: ฟอร์ม Add/Edit Employee]

### Salaries

ใช้กำหนดฐานเงินเดือนของพนักงาน

ขั้นตอนใช้งาน:

1. เปิดเมนู `Employees > Salaries`
2. เลือกหรือค้นหาพนักงาน
3. กรอกเงินเดือนหรือปรับข้อมูลเงินเดือน
4. กด `Save`

ข้อควรระวัง:

- ควรกำหนดเงินเดือนก่อนรัน Payroll
- การแก้ไขเงินเดือนอาจมีผลกับรอบเงินเดือนถัดไปหรือรอบที่ยังไม่ปิด

[ใส่ภาพหน้าจอ: หน้า Salaries]

### Employee Earnings

ใช้กำหนดรายได้ประจำของพนักงาน เช่น ค่าตำแหน่ง ค่าโทรศัพท์ หรือรายได้ประจำอื่น ๆ

ขั้นตอนใช้งาน:

1. เปิดเมนู `Employees > Employee Earnings`
2. กด `+ Add Employee Earning`
3. เลือกบริษัท พนักงาน และประเภทเงินได้
4. กรอกจำนวนเงิน
5. กด `Save`

ข้อควรระวัง:

- ใช้สำหรับรายได้ประจำของพนักงาน ไม่ใช่โบนัสเฉพาะรอบ
- ต้องสร้าง Earning Type ไว้ก่อนในเมนู Payroll Config

[ใส่ภาพหน้าจอ: หน้า Employee Earnings]

### Employee Deductions

ใช้กำหนดรายการหักประจำของพนักงาน เช่น กองทุน เงินกู้ หรือรายการหักอื่น ๆ

ขั้นตอนใช้งาน:

1. เปิดเมนู `Employees > Employee Deductions`
2. กด `+ Add Employee Deduction`
3. เลือกบริษัท พนักงาน และประเภทเงินหัก
4. กรอกจำนวนเงิน
5. กด `Save`

ข้อควรระวัง:

- ใช้สำหรับรายการหักประจำ ไม่ใช่รายการหักครั้งเดียวเฉพาะรอบ
- ต้องสร้าง Deduction Type ไว้ก่อนในเมนู Payroll Config

[ใส่ภาพหน้าจอ: หน้า Employee Deductions]

## Attendance

### Timelogs

ใช้บันทึกเวลาเข้างานและออกงานของพนักงาน

ขั้นตอนเพิ่มเวลา:

1. เปิดเมนู `Attendance > Timelogs`
2. กด `+ Add Time Log`
3. เลือกบริษัทและพนักงาน
4. เลือกสถานที่ทำงาน
5. กรอกเวลา Check In และ Check Out
6. กด `Save`

ข้อควรระวัง:

- เมื่อเลือกบริษัทแล้ว รายชื่อพนักงานและสถานที่ทำงานจะเปลี่ยนตามบริษัท
- หากเวลาออกงานน้อยกว่าหรือเท่ากับเวลาเข้างาน ระบบถือว่าเป็นการออกงานวันถัดไป เช่น 16:00 ถึง 00:00
- ข้อมูลเวลาใช้คำนวณรายได้หรือรายการหักจากการมาสาย ขาดงาน หรือทำงานเพิ่มเติม

[ใส่ภาพหน้าจอ: หน้า Timelogs]
[ใส่ภาพหน้าจอ: ฟอร์ม Add/Edit Time Log]

### Leave Requests

ใช้บันทึกคำขอลาของพนักงาน

ขั้นตอนสร้างคำขอลา:

1. เปิดเมนู `Attendance > Leave Requests`
2. กด `+ Add Leave Request`
3. เลือกบริษัท พนักงาน และประเภทการลา
4. เลือกวันที่เริ่มลาและวันที่สิ้นสุด
5. กรอกเหตุผลถ้ามี
6. กด `Save`

ข้อควรระวัง:

- โดยทั่วไปแก้ไขได้เฉพาะรายการที่ยังเป็น `Pending`
- ควรเลือก Leave Type ให้ถูกต้อง เพราะบางประเภทมีผลต่อเงินเดือน
- วันที่ลาเป็นข้อมูลแบบรายวัน ไม่ใช่เวลาเป็นชั่วโมง

[ใส่ภาพหน้าจอ: หน้า Leave Requests]

### Leave Approved

ใช้อนุมัติหรือปฏิเสธคำขอลา

ขั้นตอนใช้งาน:

1. เปิดเมนู `Attendance > Leave Approved`
2. ตรวจสอบรายการคำขอที่รออนุมัติ
3. กดอนุมัติหรือปฏิเสธตามนโยบายบริษัท
4. ตรวจสอบสถานะหลังดำเนินการ

ข้อควรระวัง:

- การอนุมัติการลาอาจมีผลต่อการคำนวณเงินเดือน
- ควรตรวจสอบช่วงวันที่ลาและประเภทการลาก่อนอนุมัติ

[ใส่ภาพหน้าจอ: หน้า Leave Approved]

### Earning Summary

ขั้นตอนใช้งาน:

2. เลือกช่วงวันที่หรือบริษัทตามตัวกรอง
3. ตรวจสอบรายการสรุป

ข้อควรระวัง:

- ใช้ตรวจสอบก่อนรัน Payroll เพื่อให้ข้อมูลเวลาและรายได้ถูกต้อง

[ใส่ภาพหน้าจอ: หน้า Earning Summary]

## Payroll Processing

### Payroll Cycles

ใช้สร้างและปิดรอบเงินเดือน เช่น January 2026 หรือ February 2026

ขั้นตอนสร้างรอบเงินเดือน:

1. เปิดเมนู `Payroll Processing > Payroll Cycles`
2. กด `Create New Cycle`
3. เลือกบริษัท
4. กรอกชื่อรอบ เช่น March 2026
5. เลือกวันที่เริ่มและวันที่สิ้นสุด
6. กด `Create Cycle`

ขั้นตอนปิดรอบ:

1. ตรวจสอบว่าคำนวณเงินเดือนเรียบร้อยแล้ว
2. กด `Close` ที่รอบเงินเดือน
3. ยืนยันการปิดรอบ

ข้อควรระวัง:

- เมื่อปิดรอบแล้ว ข้อมูลบางส่วนในรอบนั้นอาจแก้ไขไม่ได้
- ควรตรวจสอบเงินเดือน รายได้ หัก และเวลาให้ครบก่อนปิดรอบ

[ใส่ภาพหน้าจอ: หน้า Payroll Cycles]

### Cycle Earnings

ใช้เพิ่มรายได้เฉพาะรอบ เช่น โบนัสประจำเดือนหรือค่าคอมมิชชันครั้งเดียว

ขั้นตอนใช้งาน:

1. เปิดเมนู `Payroll Processing > Cycle Earnings`
2. เลือกรอบเงินเดือน
3. กด `+ Add Variable Earning`
4. เลือกพนักงานและประเภทเงินได้
5. กรอกจำนวนเงิน
6. กด `Save`

ข้อควรระวัง:

- ใช้กับรอบเงินเดือนที่ยังไม่ปิดเท่านั้น
- รายการนี้ต่างจาก Employee Earnings ซึ่งเป็นรายได้ประจำ

[ใส่ภาพหน้าจอ: หน้า Cycle Earnings]

### Cycle Deductions

ใช้เพิ่มรายการหักเฉพาะรอบ เช่น หักเงินกู้พิเศษหรือหักค่าเสียหายเฉพาะเดือน

ขั้นตอนใช้งาน:

1. เปิดเมนู `Payroll Processing > Cycle Deductions`
2. เลือกรอบเงินเดือน
3. กด `+ Add Variable Deduction`
4. เลือกพนักงานและประเภทเงินหัก
5. กรอกจำนวนเงิน
6. กด `Save`

ข้อควรระวัง:

- ใช้กับรอบเงินเดือนที่ยังไม่ปิดเท่านั้น
- รายการนี้ต่างจาก Employee Deductions ซึ่งเป็นรายการหักประจำ

[ใส่ภาพหน้าจอ: หน้า Cycle Deductions]

### Run Payroll

ใช้ประมวลผลเงินเดือนของรอบที่เลือก

ขั้นตอนใช้งาน:

1. เปิดเมนู `Payroll Processing > Run Payroll`
2. เลือกรอบเงินเดือน
3. ตรวจสอบค่าตั้งต้น เช่น SSO และการคำนวณที่เกี่ยวข้อง
4. กด `Run Calculation`
5. ตรวจสอบผลลัพธ์ เช่น Gross Pay, Deduction และ Net Pay

ข้อควรระวัง:

- การรันซ้ำจะคำนวณผลลัพธ์ใหม่จากข้อมูลล่าสุด
- ควรตรวจสอบข้อมูลพนักงาน เงินเดือน รายได้ หัก เวลา และการลาก่อนรัน
- หากพบยอดผิด ให้แก้ข้อมูลต้นทาง แล้วรันใหม่ก่อนปิดรอบ

[ใส่ภาพหน้าจอ: หน้า Run Payroll ก่อนรัน]
[ใส่ภาพหน้าจอ: ผลลัพธ์หลัง Run Calculation]

### Transaction

ใช้ดูผลลัพธ์เงินเดือนของพนักงานในรอบที่เลือก และดูรายละเอียดสลิป

ขั้นตอนใช้งาน:

1. เปิดเมนู `Payroll Processing > Transaction`
2. เลือกรอบเงินเดือน
3. ตรวจสอบรายการพนักงานและยอดเงิน
4. กดดูรายละเอียดหรือสลิปของรายการที่ต้องการ

ข้อควรระวัง:

- ข้อมูลในหน้านี้มาจากการ Run Payroll
- หากยังไม่รัน Payroll จะไม่มีรายการหรือยอดอาจยังไม่อัปเดต

## Payroll Config

### Global Settings

ใช้ตั้งค่าการคำนวณเงินเดือนของแต่ละบริษัท เช่น SSO อัตราภาษี หรือค่าตั้งต้นของ Payroll

ขั้นตอนใช้งาน:

1. เปิดเมนู `Payroll Config > Global Settings`
2. เลือกบริษัท
3. กด `Initial Setup` หรือ `Update Setup`
4. กรอกค่าตั้งต้น
5. กด `Save Config`

ข้อควรระวัง:

- ค่าตั้งต้นมีผลต่อการคำนวณ Payroll
- ควรให้ Payroll หรือ Admin เป็นผู้แก้ไขเท่านั้น

[ใส่ภาพหน้าจอ: หน้า Global Settings]

### Earning Types

ใช้กำหนดประเภทเงินได้ เช่น Base Salary, Overtime, Position Allowance

ขั้นตอนใช้งาน:

1. เปิดเมนู `Payroll Config > Earning Types`
2. กด `+ Add Earning Type`
3. เลือกบริษัทและหมวดหมู่
4. กรอกชื่อประเภทเงินได้
5. กด `Save`

ข้อควรระวัง:

- ประเภทเงินได้ที่ถูกใช้งานแล้วอาจลบไม่ได้
- ควรตั้งชื่อให้ชัดเจนเพื่อให้อ่านรายงานได้ง่าย

[ใส่ภาพหน้าจอ: หน้า Earning Types]

### Deduction Types

ใช้กำหนดประเภทเงินหัก เช่น Provident Fund, Loan Repayment, Income Tax

ขั้นตอนใช้งาน:

1. เปิดเมนู `Payroll Config > Deduction Types`
2. กด `+ Add Deduction Type`

### Permission

ใช้กำหนดสิทธิ์ของแต่ละบทบาท เช่น View, Create, Edit, Delete และขอบเขตข้อมูล

ขั้นตอนใช้งาน:

1. เปิดเมนู `Settings > Permission`
2. เลือก Role ที่ต้องการตั้งค่า
3. ติ๊กสิทธิ์ของแต่ละเมนู เช่น View, Create, Edit, Delete
4. เลือก Data Scope ตามความเหมาะสม
5. กด `Save Permissions`

ตัวอย่างการกำหนดสิทธิ์:

| บทบาท | สิทธิ์ที่เหมาะสม |
|---|---|
| Admin | ใช้งานได้ทุกเมนู |
| HR | จัดการ Employees, Attendance และ Settings บางส่วน |
| Payroll | ใช้งาน Payroll Processing, Payroll Config และ Reports |
| Manager | ดูข้อมูลทีม อนุมัติลา หรือดูรายงานที่เกี่ยวข้อง |
| Staff | ดูข้อมูลที่ตนเองได้รับสิทธิ์ |

ข้อควรระวัง:

- หากไม่ให้สิทธิ์ View ผู้ใช้จะไม่เห็นเมนูนั้น
- ควรให้สิทธิ์ Delete เฉพาะผู้ดูแลระบบหรือหัวหน้างานที่จำเป็น
- Data Scope มีผลต่อข้อมูลบริษัทหรือพนักงานที่ผู้ใช้มองเห็น

## ลำดับการทำงานที่แนะนำ

สำหรับเริ่มใช้งานระบบครั้งแรก:

1. Admin ตั้งค่า `Companies`
2. Admin หรือ HR ตั้งค่า `Department`, `Position`, `Employment Types`, `Roles`, `Permission`
3. HR ตั้งค่า `Attendance Settings`, `Holiday Calendar`, `Day Off`, `Work Locations`, `Leave Types`
4. Payroll ตั้งค่า `Global Settings`, `Earning Types`, `Deduction Types`
5. HR เพิ่มพนักงานใน `Employee List`
6. HR หรือ Payroll กำหนด `Salaries`, `Employee Earnings`, `Employee Deductions`
7. HR บันทึก `Timelogs` และ `Leave Requests`
8. Manager หรือ HR อนุมัติลาใน `Leave Approved`
9. Payroll สร้าง `Payroll Cycles`
10. Payroll เพิ่มรายการเฉพาะรอบใน `Cycle Earnings` และ `Cycle Deductions`
11. Payroll รันเงินเดือนใน `Run Payroll`
12. Payroll ตรวจผลใน `Transaction` และ `Reports`
13. Admin หรือ Payroll ปิดรอบเงินเดือนใน `Payroll Cycles`

[ใส่ภาพหน้าจอ: Flow การทำงาน Payroll ประจำเดือน]

## เช็กลิสต์ก่อน Run Payroll

- ตรวจสอบข้อมูลพนักงานครบถ้วน
- กำหนดเงินเดือนใน Salaries แล้ว
- ตั้งค่า Employee Earnings และ Employee Deductions แล้ว
- บันทึก Timelogs ครบตามรอบเงินเดือน
- ตรวจสอบ Leave Requests และอนุมัติรายการที่จำเป็นแล้ว
- ตรวจสอบ Earning Summary และ Deduction Summary
- ตรวจสอบ Cycle Earnings และ Cycle Deductions
- ตรวจสอบ Global Settings ของบริษัท
- เลือกรอบเงินเดือนถูกต้อง

## เช็กลิสต์ก่อนปิดรอบเงินเดือน

- Run Payroll สำเร็จแล้ว
- ตรวจ Transaction แล้ว
- ตรวจ Payslips แล้ว
- ตรวจ Bank Transfer แล้ว
- ตรวจ Tax Forms และ SSO แล้วถ้าเกี่ยวข้อง
- ส่งข้อมูลให้ผู้เกี่ยวข้องตรวจสอบแล้ว
- ยืนยันว่าไม่ต้องแก้ไขข้อมูลในรอบนั้นเพิ่มเติม

## คำถามที่พบบ่อย

### ไม่เห็นเมนูที่ต้องการ ต้องทำอย่างไร

ให้ติดต่อ Admin เพื่อตรวจสอบ Role และ Permission ของผู้ใช้

### เพิ่มพนักงานแล้วไม่เห็นใน Payroll ต้องทำอย่างไร

ตรวจสอบบริษัทของพนักงาน สถานะพนักงาน เงินเดือน และรอบ Payroll ว่าตรงกันหรือไม่

### ยอดเงินเดือนผิด ต้องแก้ที่ไหน

ตรวจตามลำดับนี้: Salaries, Employee Earnings, Employee Deductions, Timelogs, Leave Requests, Cycle Earnings, Cycle Deductions และ Global Settings จากนั้น Run Payroll ใหม่

### ลบข้อมูลไม่ได้ เพราะอะไร

ข้อมูลบางประเภทลบไม่ได้เมื่อถูกใช้งานแล้ว เช่น Department, Position, Bank, Earning Type หรือ Leave Type เพื่อป้องกันรายงานย้อนหลังเสียหาย

### รายงานไม่มีข้อมูล ต้องทำอย่างไร

ตรวจสอบว่ามี Payroll Cycle และได้ Run Payroll แล้ว รวมถึงตรวจสิทธิ์การเข้าถึงบริษัทหรือข้อมูลของผู้ใช้
